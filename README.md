# Skyrock Interiors Limited — Official Website

A luxury, high-performance, conversion-focused website custom-built for **Skyrock Interiors Limited** (Kenya).

---

## 🌟 Brand & Design Philosophy
- **Identity:** Luxury architectural joinery & contemporary finishing.
- **Color Palette:** Deep Obsidian & Graphite (`#07090E`, `#0C0F17`) paired with metallic Champagne Warm Gold (`#D4AF37`, `#F7E2A9`) and crisp ivory tones.
- **Typography:** Classic luxury serif (*Playfair Display* & *Cinzel*) combined with geometric sans-serif (*Plus Jakarta Sans*).

---

## 🚀 Key Interactive Features Built-In

1. **Brand Hero & Hotline Badges:**
   - Highlights the core motto: *"Transform Your House Into A Home You'll Love"*.
   - Direct click-to-call hotlines (`0745 918 724` & `0716 223 230`).
   - Quick trust badges: 5-Year Craftsmanship Guarantee, 14–21 Day Precision Delivery, Nairobi & Nationwide Coverage.

2. **Interactive Before & After Transformation Slider:**
   - Inspired directly by the before-and-after villa transformation featured on Skyrock's profile.
   - Smooth horizontal touch/mouse scrubber comparing raw blockwork vs. finished modern estate.

3. **Interactive Project Cost & Material Estimator:**
   - Real-time quote calculator for kitchens, wardrobes, TV media units, gypsum ceilings, and turnkey finishing.
   - Calculates estimated budgets in **KES (Kenyan Shillings)**.
   - **"Send Estimate to WhatsApp"** button: instantly formats selected specs and opens WhatsApp to **+254 745 918 724**.

4. **Curated Handover Portfolio:**
   - Filterable by *All*, *Kitchens*, *Wardrobes*, *TV Units*, and *Full Finishing*.
   - Lightbox modal with high-resolution imagery, location tags (Karen, Runda, Kileleshwa, Kilimani), timeframes, and material specs.

5. **Our 4-Step Craftsmanship Process:**
   - 1. Free Site Assessment & Laser Measurements
   - 2. 3D Architectural CAD Renderings & Material Curation
   - 3. Precision Factory Joinery & CNC Fabrication
   - 4. Clean Site Installation & 5-Year Handover Warranty

6. **Materials & Hardware Quality Deep-Dive:**
   - Detailed breakdown of moisture-resistant marine/E1 boards, anti-scratch acrylics, German soft-close Blum hinges, and engineered quartz.

7. **Verified Client Testimonials & Kenyan FAQs:**
   - Real testimonials from homeowners in Nairobi estates.
   - Accordion answering questions on site visits, warranties, timelines, and 3D previews.

8. **Direct WhatsApp & Phone Hotline Integration:**
   - Floating WhatsApp pulsing button with pre-filled enquiry text.
   - Sticky consultation booking modal with celebratory confetti on submission.

## 🛠️ How to Run & Deploy

### Quick Start
Double-click `start-website.bat` or run:
```bash
# Start local preview
npm run preview

# Or start live development server
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

### Production Build
```bash
npm run build
```
The optimized production files are generated in the `dist/` directory, ready to deploy instantly to:
- **Vercel:** Run `npx vercel` or link your GitHub repo.
- **Netlify:** Drag and drop the `dist/` folder into Netlify Drop.
- **Custom Domain:** Host on any standard web hosting or VPS.
